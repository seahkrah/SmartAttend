# JjeloTech design mockups

`JjeloTech Mockups.html` is the exported Claude Design document, self-contained:
fonts and images are embedded in the `__bundler/manifest` script block, and the
design itself is the JSON-encoded HTML in `__bundler/template`.

Open it in a browser to view. It renders a canvas of 20 screens grouped into
six rounds (`t1`–`t6`).

See `DESIGN_AUDIT.md` at the repository root for how these screens map onto the
existing application.
