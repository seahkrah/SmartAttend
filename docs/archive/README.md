# Archive: historical reports

These files were written during earlier phases of the project: phase plans,
"complete" reports, quick references and status summaries. They are kept for
history. **They are not documentation of the current system.**

Many of them describe things that were later found to be untrue or have since
changed. For example:

- face "recognition" that compared browser-supplied numbers and accepted any
  face;
- an MFA middleware that accepted any code;
- default passwords such as first initial + surname + "123";
- metrics, incident and time-authority endpoints that could only return errors
  or 401;
- statuses and fields the database does not have.

For how the system works now, start at the repository [README](../../README.md)
and the documents under `docs/` outside this folder.
